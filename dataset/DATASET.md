# Набор данных для обучения нейросети синтеза ДОЭ

## Что это
Сети не нужны готовые ДОЭ: она учится через физическую модель (дифракция Френеля),
поэтому набор данных - это только **изображения-цели**.

## Источник
* Фактический источник: **tinyimagenet** (параметр `--data auto`); банк - **110000** картинок.
* Tiny-ImageNet (HuggingFace [`zh-plus/tiny-imagenet`](https://huggingface.co/datasets/zh-plus/tiny-imagenet), части `train` 100 000 + `valid` 10 000) - подмножество ImageNet, 200 классов, цветные фото 64x64; используется для исследовательских целей, как и сам ImageNet.

## Обработка
1. Каждое фото переводится в оттенки серого (8 бит) и, если нужно, приводится к 64x64.
2. Разбиение: 2% банка (**2200** картинок) - отложенная выборка для выбора лучшей модели
   (сеть их не видит), остальное - обучение. Перемешивание с seed=0.
3. Обучающий пример (генерируется на лету, каждый раз новый):
   * 4 случайные картинки банка, случайный фрагмент 62x62;
   * случайные отражения / транспонирование, гамма 0.64-1.57, контраст и уровень чёрного;
   * картинка k кладётся в свой угол чёрного кадра 128x128 - ровно как в проверке:
     1: строки/столбцы [0:62, 0:62], 2: [0:62, 66:128], 3: [66:128, 0:62], 4: [66:128, 66:128].
   Число разных комбинаций практически бесконечно, поэтому переобучения нет.

## Файлы
* `samples/NNNN/1.png ... 4.png` - 50 примеров обучающих входов в формате задания.
* `samples_preview.png` - мозаика из первых примеров.
* `bank_gray64.npz` - весь банк (`bank`: uint8 [N,64,64], `val_indices`, `train_indices`).

## Как воспроизвести
```
python export_dataset.py --data auto --n_images 110000 --out dataset --full
```
